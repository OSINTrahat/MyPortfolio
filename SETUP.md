# OSINTrahat portfolio setup

This is a fork of ElMehdiBekkous/MyPortfolio, customized for OS RAHAT / OSINTrahat.

## Run locally

```bash
git clone https://github.com/OSINTrahat/MyPortfolio.git
cd MyPortfolio
npm install
npm run dev
```

Open http://localhost:3000

## Deploy (Vercel — recommended)

1. Go to https://vercel.com/new
2. Import `OSINTrahat/MyPortfolio`
3. Framework: Next.js (auto)
4. Deploy

Live demo of the original template: https://elmehdibekkousportfolio.vercel.app
